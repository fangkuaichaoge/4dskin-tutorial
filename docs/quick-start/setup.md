# 准备工具

## 必备工具

### 代码编辑器

用于编辑 JSON 文件，推荐使用以下工具：

- **Visual Studio Code**（推荐）
  - 下载链接：<https://code.visualstudio.com/>
- **MT 文件管理器**（手机端）
  - 下载链接：<https://mt2.cn/download/>
- **普通文本编辑器**（最低要求）

### Blockbench

用于创建和编辑皮肤模型，支持网页版和桌面端：

- **Blockbench**
  - 链接：<https://www.blockbench.net/>
  - 网页版直接在浏览器中打开，无需安装
  - 桌面端功能更完整，推荐使用

## 可选工具

### Blender

用于编辑和优化网格模型（主要用于 5D 皮肤教程）：

- **Blender**
  - 下载链接：<https://www.blender.org/download/>
